# Prem-Lichtwerbung Style Guide

## Brand Identity

### Core Values
- Visible: Clear communication, professional presence
- Modern: Contemporary design, up-to-date technology
- Trustworthy: Reliable, precise, quality-focused
- Technical: Professional, streamlined, expert

### Tone of Voice
- Clear and concise
- Practical and direct
- Strong call-to-actions
- Minimal marketing fluff
- Professional but approachable

## Visual Design

### Color Palette

**Primary Color**
- Primary: #FFB400 (Amber/Gold)
- Use: CTAs, highlights, important elements

**Accent Color**
- Accent: #00D1FF (Cyan)
- Use: Links, secondary CTAs, illumination effects

**Backgrounds**
- Background: #0B0D1A (Dark Navy)
- Surface: #14172C (Dark Surface)
- Surface Alt: #1A1D34 (Lighter Surface)

**Text Colors**
- Text Main: #F3F4FA (Light Text)
- Text Muted: #9CA0C1 (Muted Text)

### Typography

**Headings**
- Font: Space Grotesk
- Weights: Normal (400), Medium (500), Semibold (600), Bold (700)
- Sizes: H1 (text-3xl to 4xl), H2 (2xl), H3 (xl)

**Body Text**
- Font: Inter
- Weight: Regular (400), Medium (500), Semibold (600)
- Size: Base (16px)

### Effects & Styling

**Minimal Approach**
- Use glow effects ONLY for illumination previews
- No heavy gradients
- No playful animations
- Subtle transitions only

**Shadows**
- Minimal card shadows
- Subtle borders instead of heavy shadows

## Components

### Before/After Slider
- Day/night product views
- Case study comparisons
- Clean, simple controls

### Cards
- Subtle borders (1px)
- Minimal shadows
- Clean, spacious layout

### Buttons
- Primary: Solid #FFB400, no gradients
- Secondary: Outlined, minimal style
- No heavy effects or animations

### Product Imagery
- High-quality, real installations
- Day and night views
- Professional photography only

## Layout & Structure

### Hierarchy
- Clear value proposition immediately visible
- Product visuals prominent
- Strong, visible CTAs
- Minimal clutter

### Hero Sections
- Clear message
- Strong CTA
- Product image or day/night slider
- No distracting backgrounds

### Trust Elements
- Short, visible badges
- Weatherproof, warranty, production time
- Certifications displayed clearly

## Mobile Design

### Requirements
- Full-width CTAs
- Simplified navigation
- Easy tap targets (44px minimum)
- Optimized images
- Fast loading

## Accessibility

### Standards
- WCAG AA contrast compliance
- Visible focus states
- Keyboard navigation
- Screen reader friendly

## Technical Implementation

### Vue 3 Components
- Before/after slider with props
- Reusable card components
- Consistent spacing utilities

### Directus Fields
- day_image and night_image fields
- Structured product data
- Case study collections

### Performance
- Lazy loading images
- Optimized fonts
- Minimal animations
- Fast page loads
