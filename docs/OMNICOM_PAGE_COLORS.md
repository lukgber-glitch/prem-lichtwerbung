## RESEARCH INSTRUCTIONS

### Step 1: Visit Each Page
Navigate to omnicomgroup.com and visit each page listed above.

### Step 2: Identify Accent Colors
Look for:
- Lines/dividers before headlines
- Hover states on links/buttons
- CTA button background colors
- Underline colors on active navigation
- Border colors on interactive elements

### Step 3: Extract Hex Values
1. Right-click on colored element → Inspect
2. In DevTools Styles panel, find the color property
3. Click color swatch to see hex value
4. Copy exact hex value (e.g., `#AD342A`)

- Capture each page showing accent color usage
